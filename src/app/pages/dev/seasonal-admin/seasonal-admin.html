Como personalizar no código

Não há editor de slots neste painel. Altere os arquivos abaixo e faça deploy/reload.

  1. Defaults do tema — edite src/app/models/seasonal/themes/*.theme.ts (ex.: natal.theme.ts). Em slots você define:
    • logo.overlay: none | hat | badge
    • topbar.accent: cor hex + ligado/desligado
    • ambient.effect: none | snow | flags | petals | sparkle
    • greeting.message / icon
  2. Janela de datas — no mesmo arquivo, campo windows (mês/dia início e fim) controla o modo automático.
  3. Visual do efeito — SCSS em src/app/theme/seasonal/_effects-*.scss e overlays de logo em _logo-overlays.scss. Seletores usam data-season-ambient / data-season-logo.
  4. Novo efeito — 1) union em seasonal.types.ts → 2) arquivo _effects-novo.scss + import em seasonal-theme.scss → 3) use o efeito no slots.ambient do tema.
  5. Novo tema — crie meu-tema.theme.ts, registre em models/seasonal/themes/index.ts (lista + prioridade).
